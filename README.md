# 手表排版 (Watch Layout)

为《明日方舟：终末地》提供 ESC 主菜单布局整理功能。内置可视化全屏拖拽编辑器，可自由调整主菜单各功能入口的排列顺序与隐藏状态。

## 功能特性

- **可视化拖拽排序**：直接用鼠标按住卡片拖动交换位置，松开即保存。
- **隐藏不常用入口**：支持将卡片拖入右下角的「已隐藏」区域，精简菜单显示。
- **保留原生功能逻辑**：仅调整排版与展示，红点提示、功能解锁条件及点击跳转均不受影响。
- **即时生效**：调整完毕后退出编辑器即可在 ESC 菜单中即时生效。

## 使用方法

1. 确保已安装 ZML 与模组菜单。
2. 游戏内按 `ESC` →「模组菜单」→「手表排版」→「模组配置」打开拖拽编辑器。
3. 拖拽卡片调整布局，或拖入「已隐藏」区；点击左上角返回即可应用。
