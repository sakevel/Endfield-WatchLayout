# 测试与验证指南

本文档介绍 Endfield-WatchLayout（ESC 菜单整理模组）的自动化测试套件与功能验证方法。

---

## 自动化测试

项目包含 Native C++ 合约测试与 Python / Lua 布局逻辑测试：

```powershell
ctest --test-dir build -C Release --output-on-failure
```

### 测试套件说明

- **ContractTests (`tests/contract_tests.cpp`)**：
  - 验证模组导出函数 `ZML_PluginV1` 与头文件 ABI 规范。
  - 验证对原生 `WatchCtrl` 脚本的修补锚点唯一性，确保正确拦截 `RIGHT_BTN_ORDER` 的重排时机。

- **BehaviorTests (`tests/behavior_tests.py` / `tests/mock.lua`)**：
  - **布局格式序列化与反序列化**：验证三区（左侧、右侧、隐藏区）字符串布局配置的编解码。
  - **历史版本兼容迁移**：测试旧版双栏配置平滑迁移至三区配置。
  - **边界用例保护**：验证缺失入口补全、重复 ID 去重及非法字符过滤。

---

## 实机功能验证清单

在游戏内测试时，可按照以下流程逐项验证：

1. **可视化编辑器打开**：
   - 在模组菜单中打开 ESC 菜单整理配置，确认全屏编辑器顺利展开，各区域卡片排布正常。

2. **卡片拖拽与排序**：
   - 拖拽右侧列表中的卡片改变顺序，松开后卡片准确停留在新位置。
   - 将卡片拖动到左侧大卡槽位，确认异形卡片外观与展示正常。
   - 将卡片拖入「已隐藏」区域，确认对应卡片移入隐藏列表。

3. **ESC 菜单呈现效果**：
   - 返回游戏 ESC 主菜单，确认界面入口已按自定义顺序排布。
   - 点击重排后的各按钮，确认功能跳转正常。
   - 点击「布局已启用」按钮切换为停用状态，确认 ESC 菜单能立即恢复官方默认排布。
