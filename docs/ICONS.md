# 图标设计与导出说明

本文档说明 Endfield-WatchLayout 的图标规范与导出流程。

---

## 图标规范

- **模组图标** (`mod/icon.png`)：
  256×256 透明 RGBA PNG，基于终末地工业风格设计。
  图标以左右布局卡片和双向交换箭头为主体，直观表达 ESC 菜单左右入口迁移与重排功能。
  采用石墨灰 `#313131`、中灰与纯白面板，并在角标辅以 `#ffef00` 亮黄点缀。

---

## 导出流程

从高分辨率源图生成发布图标：

```powershell
python tools/export-icon.py
```
